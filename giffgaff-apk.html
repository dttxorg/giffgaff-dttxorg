第 2 步

安装到手机

Android 手机（小米 / OPPO / vivo / 三星 / 一加等）

1. 打开文件管理，找到刚下载的 giffgaff.apk
2. 点一下 → 手机会提示"未知来源应用"风险
3. 去 设置 → 隐私 / 安全 → 安装未知应用，给"文件管理"或"浏览器"开权限
4. 返回点 giffgaff.apk → 安装 → 完成

鸿蒙 / HarmonyOS 手机（华为）

1. 打开 设置 → 隐私 → 隐私保护 → 权限管理
2. 找到浏览器或文件管理，给"安装外部来源应用"权限
3. 返回点击 APK 安装

装完提示"应用未安装"怎么办？

99% 是因为之前装过旧版本/签名不一致。解决：
· 先 卸载旧版（设置 → 应用 → giffgaff → 卸载）
· 然后重新装新 APK

装完提示"有害应用"被拦截？

MIUI / ColorOS / OriginOS 这些系统会扫 APK，提示"可能有害"。点 仍有风险 → 安装 就行。
giffgaff 是英国上市公司 MVNO，APK 没毒。

说明

版权与使用

这个 APK 哪里来的？

来自 giffgaff 官方 Android App，版权归 giffgaff Mobile Limited 所有。本站仅作为下载镜像，方便国内用户（无法访问 Google Play）使用。

为什么不直接去 Google Play 装？

国行 Android / 鸿蒙系统没有 Google Play。直接装 APK 是这些设备唯一的方式。

会偷我数据吗？

不会。这是 giffgaff 官方应用，签名和 Play 商店版一致。
如果担心，可以在 设置 → 应用 → giffgaff → 权限 里关掉不必要的权限（位置 / 通讯录 / 存储）。

能直接通过这个 APK 买卡吗？

不能。App 只是 SIM 管理工具，**买卡需要从你下单的渠道**（链动 / 微店 / 卖家）拿到激活码或 eSIM。
